# Periodic Table

All 118 elements with a fast, zoomable table, a detail screen with an animated atom, a searchable list and a quiz. Fully offline.

## What it does
- **Table:** pinch to zoom, drag, fling, double-tap to zoom in/out. Tap an element for details. Search by name (English, Urdu or Arabic), symbol or atomic number; matches are highlighted and the rest dimmed.
- **Color by:** Category, State at room temperature, Block, or Electronegativity (gradient). In Category mode tap a legend item (or the 57-71 / 89-103 boxes) to highlight a group.
- **Element screen:** big tile, names in English/Urdu/Arabic, animated Bohr-style atom with electrons per shell, atomic mass, category, group, period, block, state, melting and boiling point (K, °C or °F), density, electronegativity, electron configuration, discovery year, share button, previous/next buttons.
- **List:** all elements sorted by atomic number or name, with search.
- **Quiz:** symbol, name and atomic-number questions with score and best streak.
- **Settings:** language (English is the default and pre-selected; Urdu and Arabic are right-to-left), light/dark mode, temperature unit.
- Exit confirmation on Back.

## Build
1. Upload the folder to GitHub.
2. Open Actions: the "Build APK" workflow runs.
3. Download the `PeriodicTable-APK` artifact.

## Limitations
- Portrait only. No AndroidX or external libraries. No permissions, no internet.
- Values are standard reference numbers (rounded) typed from reference tables; properties of the heaviest elements (especially above 100) are predicted, not measured. Verify with IUPAC or another official source for serious work.
- The f-block is shown as lanthanides La-Lu and actinides Ac-Lr.
- Urdu and Arabic element names are standard transliterations/names; a few may differ by region.
